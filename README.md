# 画面テキスト取得（strong-clipboard-android）

Android の「テキストを長押ししてもうまく選択できない」ストレスを減らすためのアプリです。

ボタン 1 つで **今表示している画面のテキストをすべて取り出し、要素ごとに番号付きで一覧表示** します。
使いたい番号を選び、必要なら編集してから OS のクリップボードへコピーできます。

## できること

- ユーザー補助ボタン（画面端の呼び出しボタン）またはクイック設定タイルから、表示中の画面のテキストを一括取得
- 取得したテキストを要素ごとに整形（改行コード・不要な空白・ゼロ幅文字の除去、重複の除去）して番号付きで表示
- 選択方法
  - 一覧をタップして選択／解除（複数可、番号順に結合）
  - `3`、`1,4-6`、`２、５〜７` のような番号指定でまとめて選択
  - 番号以外の文字を入れると一覧を絞り込み検索
  - 長押しメニュー：この項目だけコピー／編集欄に追加／行ごとに分割／全文表示
- 編集欄
  - 自由に編集可能。結合時の区切り（改行・空行・空白・なし）を切り替え
  - 「改行を削除」（日本語向け）「改行→空白」（英語向け）「空白を整理」——範囲選択していればその部分だけに適用
- 「番号付き一覧をコピー」で一覧そのものもクリップボードへ
- 「コピーして閉じる」「共有」

読み取ったテキストはメモリ上だけで扱い、保存も外部送信もしません。パスワード欄は読み取りません。
インターネット権限も持っていません。

## しくみ

Android の `AccessibilityService`（ユーザー補助サービス）で、表示中ウィンドウのビュー階層からテキストを読み取っています。
そのため、画面に「文字として」描かれているものは選択不可の場所でも取得できますが、
画像の中の文字（写真、スクリーンショット、一部のゲームや PDF ビューア、Canvas 描画）は取得できません。
その場合は Google レンズなどの OCR を使ってください。

## ビルド・インストール

- GitHub Actions が push のたびに debug APK をビルドします。Actions の実行結果ページの
  「Artifacts」から `screen-text-picker-debug-apk` をダウンロードし、端末にインストールしてください。
- 手元でビルドする場合は Android Studio でこのフォルダを開くか、Android SDK を入れた環境で
  `./gradlew assembleDebug` を実行します（JDK 17、compileSdk 35、minSdk 26 = Android 8.0）。

## 初期設定

1. アプリを開き「ユーザー補助の設定を開く」→「画面テキスト取得」をオンにする。
   ショートカット（ユーザー補助ボタン）もオンにすると呼び出しボタンが出ます。
2. **Android 13 以降で APK から入れた場合**は「制限付き設定」と表示されてオンにできないことがあります。
   その場合は「アプリ情報」→ 右上の︙ →「制限付き設定を許可」を押してから、もう一度オンにしてください。
3. 必要ならクイック設定パネルの編集画面から「画面テキスト」タイルを追加してください。

## 既知の制限

- Web ページなどで、スクロールしないと見えない部分は既定では取得しません（設定でオンにできます。
  ただしアプリによっては画面外の要素をそもそも持っていません）。
- Google Play で公開する場合、ユーザー補助 API の利用目的について審査があります（個人利用の APK なら不要）。
